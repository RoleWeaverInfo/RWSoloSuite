OPTIONAL PLAYER COMPANION

AI conversations during play

The module’s complete story and quests run in NWN. This companion adds freeform chat for modules exported with optional live AI.

Return to the module authoring toolset

Start the module locally, stay near a character, and use !talk alias your message or choose “Talk freely with AI” and then type !ai your message.

Uses the player’s OPENAI_API_KEY environment variable. No credentials are contained in shared modules. Keep NWN unpaused while waiting for replies.
